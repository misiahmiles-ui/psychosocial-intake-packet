# Offline verified narrative contract

The completed, PHI-reviewed intake is the sole clinical authority. The built-in assessment is prepared first. Optional AI receives only reviewed, de-identified facts and a catalog of source-bound professional phrasings. It returns paragraph text plus ordered source IDs. Its text, when valid, is the text displayed to the clinician and included in the accepted assessment.

The validator parses each paragraph left to right. Every clinical statement must exactly match one approved phrasing for the corresponding source ID and section. Field-specific phrasings form natural clinical clauses when the source wording supports them; other values retain an explicit evidence frame. These phrasings preserve the source value, reporter type, temporal status, polarity, diagnostic and screening boundaries, and planned-service scope. Safety and screening sections remain authoritative renderings from the intake. This exact structured contract allows the model to select relevant facts, arrange them, and choose among professional phrasings without permitting an unsupported clinical assertion. It does not use sentence-wide word spotting or a second model verdict.

One provider attempt is allowed. An invalid statement can be replaced once from its cited fact, then the full narrative and output PHI scan run again. If the citations are invalid, output PHI appears, validation still fails, or no AI wording survives, the original built-in assessment is returned. Invalid AI text is never sent to the clinician. Built-in creation, AI, repair, and fallback are one assessment workflow and settle at most one use.

The contract intentionally limits free-form AI paraphrasing. An unrestricted novel sentence cannot be proven factually safe by a deterministic validator. The approved phrasings are the supported paraphrases in this implementation. This is an offline implementation; no provider call, migration, Stripe mutation, merge, or deployment has been performed for this revision.
